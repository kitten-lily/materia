Read the guide for the component or host behavior you are changing. The repository-wide design and outage guardrails live in [AGENTS.md](../../AGENTS.md).

- [Pangolin edge](pangolin-edge.md). Read when working on the shared edge pod, Traefik, badger, HTTP/3, or Pangolin resource settings.
- [Materia behaviour](materia-behaviour.md). Read when changing manifests, templates, attributes, secrets, reconciliation, or release gates.
- [Podman and Quadlet](podman-quadlet.md). Read when writing units, health checks, environment values, mounts, or non-root containers.
- [Restic and database backups](restic-backup.md). Read when changing backups, restoring a database, provisioning a Storage Box, or evaluating Proton Drive.
- [Beszel](beszel.md). Read when deploying the hub or agent, bootstrapping enrollment, or changing alerts and monitored paths.
- [Tailscale and Newt](tailscale-newt.md). Read when changing tunnel clients, the gateway, container discovery, or tailnet routing.
- [Buildbarn](buildbarn.md). Read when changing cache auth, TLS, CAS sizing, or metrics.
- [Provisioning and Flatcar](provisioning-flatcar.md). Read when rendering Ignition, provisioning or adopting hosts, or changing nftables, LVM, USB, or sysupdate.
- [Media apps and SilentSuite](media-apps.md). Read when changing media apps, SilentSuite, DB sidecars, hardlinks, image pins, or SSO.
- [Sizing benchmarks](bench.md). Read when running or comparing bench tasks and interpreting their results.
